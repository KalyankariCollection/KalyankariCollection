# Security

## Security Resources

Resources to protect your device from malware:

- [Malwarebytes](https://www.malwarebytes.com/) - Popular Comprehensive Antivirus Software
- [ConfigureDefender](https://github.com/AndyFul/ConfigureDefender) - Advanced Windows Defender Utility
- [Defender UI](https://www.cyberlock.global/DefenderUI.aspx) - Simple Windows Defender Interface
- [Sandboxie-Plus](https://sandboxie-plus.com/) - Open Source Windows Sandboxing
- [Windows Sandbox](https://learn.microsoft.com/en-us/windows/security/application-security/application-isolation/windows-sandbox/windows-sandbox-overview) - Integrated Windows Isolation Environment
- [Tria.ge](https://tria.ge/) - Interactive Malware Analysis Sandbox
- [Cuckoo Sandbox](https://cuckoo.cert.ee/) - Automated Malware Analysis System

## File Scanners

Resources for verifying the safety of files:

### Offline Scanners

- [The Second Opinion](https://jijirae.github.io/thesecondopinion/) - Portable Malware Removal Tools
- [Microsoft Safety Scanner](https://learn.microsoft.com/en-us/defender-endpoint/safety-scanner-download) - On-Demand Windows Security Scanner
- [Emsisoft Emergency Kit](https://www.emsisoft.com/en/home/emergency-kit/) - Portable Malware Cleaning Tool

### Online Scanners

- [VirusTotal](https://www.virustotal.com/) - Analyze Suspicious Files URLs
- [Hybrid Analysis](https://hybrid-analysis.com/) - Free Malware Analysis Service
- [Jotti's Malware Scan](https://virusscan.jotti.org/) - Multiple Engine File Scanner
- [FileScan](https://www.filescan.io/) - Automated Malware Analysis Platform

## Site Legitimacy Check

These can check for the legitimacy of sites and identify shady sites.

::: warning Disclaimer
Always use your best judgement; these are not 100% accurate.
:::

- [URLVoid](https://www.urlvoid.com/) - Website Reputation Check Service
- [URLScan](https://urlscan.io/) - Website Security Scan Tool
- [Trend Micro Site Safety](https://global.sitesafety.trendmicro.com/) - Web Reputation Query Service
- [ScamAdviser](https://www.scamadviser.com/) - Website Trust Score Checker
- [IsLegitSite](https://www.islegitsite.com/) - Fast Website Legitimacy Checker
- [Zscaler Zulu](https://zulu.zscaler.com/) - Dynamic Web Content Risk

## Password Managers

You should use password managers to create and manage strong, unique passwords:

- [Bitwarden](https://bitwarden.com/) - Open Source Password Manager
- [KeePass](https://keepass.info/) - Offline Open Source Manager
- [Proton Pass](https://proton.me/pass) - Secure Encrypted Identity Manager
- [LessPass](https://lesspass.com/) - Stateless Open Source Manager
- [Buttercup](https://buttercup.pw/) - Secure Cross Platform Manager
- [Spectre](https://spectre.app/) - Algorithm Based Password Generator
